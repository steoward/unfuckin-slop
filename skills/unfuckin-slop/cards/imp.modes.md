# Modes

The mode names what the visitor's success looks like on this surface.

| Mode | Success | Surfaces | Ambition shows as |
| --- | --- | --- | --- |
| **Persuade** | Decides and acts | Landing pages, marketing, campaigns, pricing | Full commitment: bold, distinct work with a point of view |
| **Operate** | Completes a task | App UI, dashboards, editors, admin, settings | Precision and restraint; patterns the visitor knows earn their place |
| **Read** | Understands something | Docs, articles, guides, help, changelogs | Structure for comprehension, then a reading experience worth staying in |
| **Experience** | Is inside the work | Portfolios, galleries, showcases | The artifact leads from the first viewport; the interface recedes |

# Choosing

Choose the mode from the requested **surface**, not the product. A tool's landing page is Persuade. A fashion house's documentation is Read. A docs index is Read, not Persuade. Persist the mode only in that surface's brief.

# Consequence

Persuade and Experience get the expressive typography, the strong colour move, the authored motion. Operate and Read get density, scanability, keyboard paths, and consistency. Applying Persuade ambition to a settings screen produces slop; applying Operate caution to a campaign produces wallpaper.
