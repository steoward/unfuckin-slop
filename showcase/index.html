Wire your agent to flunds MCP in one line.

The flunds MCP server gives any AI coding agent native tools to construct manifests, generate icon suites, configure offline service workers, and deploy web applications to mobile users globally.

{
  "mcpServers": {
    "flunds": {
      "command": "flunds-mcp",
      "args": ["--workspace", "./pwa-build"]
    }
  }
}
# Add flunds MCP directly to Claude Code
claude mcp add flunds -- npx -y @flunds/mcp-server@latest
# OpenCode / Codex configuration
[mcp.servers.flunds]
command = "flunds-mcp"
args = ["--auto-deploy", "true"]
{
  "mcpServers": {
    "flunds": {
      "url": "http://localhost:4499/sse"
    }
  }
}
flunds_create_app Scaffold

Initializes mobile PWA structure with responsive viewport, touch gesture primitives, and high-performance Web App Manifest (standalone display mode).

flunds_generate_icons Graphics

Generates complete icon matrices (192x192, 512x512, SVG, Apple touch icon, and Android adaptive maskable icons) from SVG or prompt descriptions.

flunds_configure_sw Offline

Configures Service Worker caching strategies: Cache-First for static assets, Network-First for dynamic APIs, and offline fallback screens for mobile reliability.

flunds_deploy_pwa Hosting

Uploads bundles directly to flunds edge network with automatic TLS, sub-10ms global delivery, and immediate PWA installation link and QR code generation.
